# Superstore-sales-Analysis
📊 Superstore Sales Data Analysis

This project focuses on analyzing the Superstore dataset using Python to discover meaningful business insights from sales, profit, customers, products, and shipping data.

The analysis is performed using Pandas, NumPy, Matplotlib, and Seaborn, covering data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization.

🎯 Project Objectives
Analyze overall sales and profit performance
Identify the best-performing categories and sub-categories
Find top customers and products
Analyze sales and profit across different regions and states
Understand customer segments
Analyze shipping modes and shipping time
Study the relationship between sales, discount, quantity, and profit
Identify areas with high sales but low/negative profit
Create meaningful visualizations to communicate insights
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
📌 Key Learning

Through this project, I practiced real-world data analysis using Python, including data cleaning, filtering, grouping, aggregation, correlation analysis, and data visualization. The project helped me understand how raw business data can be transformed into useful insights for decision-making.

📂 Project Workflow

Data Loading → Data Cleaning → Exploratory Data Analysis → Sales Analysis → Profit Analysis → Customer Analysis → Shipping Analysis → Correlation Analysis → Visualization → Business Insights

Note: This project is created as a learning and portfolio project to demonstrate practical data analysis skills using Python.
